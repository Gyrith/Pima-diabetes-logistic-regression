# Pima Diabetes Logistic Regression
## Pima Diabetes Logistic Regression
Logistic regression classifier predicting diabetes status from the Pima Indians dataset (via the `faraway` package), built and evaluated across two labs.

## Files

- **`CG_C07_M02.ipynb`** — Data loading, cleaning, an 80/20 train-test split, feature scaling with `StandardScaler`, and a baseline logistic regression model.
- **`CG_C07_M03.ipynb`** — Extends the model with evaluation metrics: confusion matrix, classification report, and ROC/AUC analysis.

## Dataset

Loaded directly from the `faraway` Python package (`faraway.datasets.pima`) — no external file needed.
